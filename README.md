# APS1 — Análise Exploratória de Dados: Adult Income Census

**Disciplina:** Machine Learning
**Integrantes:** Vanessa Ricoy e Victor Cunha
**Data de entrega:** 14/09/2026

## Sobre o projeto

Este repositório contém a APS1 (Etapa 1 do Projeto de Machine Learning): uma análise exploratória de dados (EDA) completa sobre o dataset [Adult Income Census](https://www.kaggle.com/datasets/anaghakp/adult-income-census), do Kaggle.

O objetivo é investigar como idade, escolaridade e ocupação se relacionam com a faixa de renda (`income`) dos registros do censo, identificando problemas de qualidade dos dados, distribuições e relações entre variáveis, e preparando o pré-processamento para a próxima etapa do projeto (classificação, na APS2).

## Relatório publicado

O relatório completo (código, gráficos e análises) está publicado via GitHub Pages:

**🔗 [vanessaricoy.github.io/aps1-adult-income](https://vanessaricoy.github.io/aps1-adult-income/)**

## Conteúdo da análise

1. Conhecendo o dataset
2. Limpeza inicial e divisão dos dados (treino/teste)
3. Análise univariada das variáveis numéricas
4. Análise univariada das variáveis categóricas
5. Análise bivariada e multivariada
6. Escolhas de pré-processamento (imputação, encoding, escala)
7. Redução de dimensionalidade com PCA
8. Conclusão
9. Referências
